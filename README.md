# Stock Portfolio Performance & Risk Analysis

## Overview

This project analyzes the performance of a diversified portfolio of 10 Indian stocks using historical market data from January 2020 to December 2025.

The analysis focuses on portfolio performance, stock returns, risk, diversification, and overall portfolio behavior using Python.

---

## Stocks Included

- Dixon Technologies
- PTC India
- Larsen & Toubro (L&T)
- Bharat Electronics (BEL)
- State Bank of India (SBI)
- Trent
- Infosys
- Adani Enterprises
- Indian Oil Corporation (IOC)
- Cummins India

The stocks were selected from different sectors to create a diversified portfolio.

---

## Project Workflow

- Collected historical stock prices using yfinance
- Cleaned and prepared the dataset
- Compared stock price movements
- Normalized prices for fair comparison
- Calculated daily returns
- Measured annual return and annual risk
- Built an equal-weight portfolio
- Calculated portfolio growth
- Compared risk vs return
- Analyzed stock correlations
- Calculated Sharpe Ratio
- Performed drawdown analysis
- Identified the best and worst performing stocks

---

## Key Findings

- The portfolio generated an annual return of approximately **37%**.
- The annual portfolio risk was around **22%**.
- The Sharpe Ratio was **1.40**, indicating good risk-adjusted performance.
- Dixon Technologies delivered the highest overall return during the analysis period.
- The portfolio remained reasonably diversified, with most stocks showing low to moderate correlation.
